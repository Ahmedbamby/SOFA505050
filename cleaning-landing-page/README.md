# صفحة هبوط جو أجواء للخدمات المنزلية

صفحة عربية بسيطة وسريعة ومتجاوبة لشركة جو أجواء للخدمات المنزلية، للتعريف بخدمات التنظيف والمكيفات والخزانات والعزل ومكافحة الحشرات، مع أزرار واتساب واتصال مباشر وTikTok Pixel.

## التشغيل محلياً

لا تحتاج الصفحة إلى تثبيت أي حزم. افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادم ملفات ثابت داخل المجلد.

مثال:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الرفع على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
3. من إعدادات المستودع افتح **Pages**.
4. اختر النشر من الفرع الرئيسي والمجلد الجذري `/root`.
